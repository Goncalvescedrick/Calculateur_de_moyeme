# Calculateur de Moyenne S3

Une application web simple et moderne pour calculer la moyenne de vos modules du troisième semestre (S3), ainsi que votre moyenne générale.

## 🚀 Fonctionnalités

*   **Ajout de notes et coefficients** : Saisissez deux notes (sur 20) et le coefficient pour chaque module.
*   **Modules personnalisés** : Sélectionnez des modules pré-existants ou ajoutez vos propres modules personnalisés. Les nouveaux modules sont **sauvegardés automatiquement** pour vos prochaines utilisations.
*   **Calcul de la moyenne** : Obtenez en temps réel la moyenne de chaque module et votre moyenne générale pondérée.
*   **Estimation de la mention** : L'application vous donne une estimation de la mention associée à votre moyenne générale (Passable, Assez Bien, Bien, etc.).
*   **Sauvegarde automatique** : Grâce au `localStorage`, vos notes et modules saisis sont conservés même si vous fermez ou rafraîchissez la page. Vous ne perdrez jamais vos données !
*   **Raccourcis clavier** : Appuyez sur la touche "Entrée" lors de la saisie de vos notes pour ajouter le module rapidement sans avoir à utiliser la souris.
*   **Design moderne et responsive** : L'interface s'adapte à la taille de votre écran (ordinateur, tablette ou mobile) pour une expérience utilisateur optimale.

## 🛠️ Utilisation

Ce projet est constitué d'un simple fichier HTML contenant tout le code nécessaire (HTML, CSS et JavaScript). Aucune installation ni configuration serveur n'est requise.

1.  Ouvrez simplement le fichier `Calculateur.html` dans n'importe quel navigateur web moderne (Chrome, Firefox, Edge, Safari...).
2.  Sélectionnez un module dans la liste déroulante ou choisissez **"Autre..."** pour créer le vôtre.
3.  Entrez vos deux notes et le coefficient.
4.  Cliquez sur **Ajouter** ou appuyez sur `Entrée`.
5.  Une fois tous vos modules ajoutés, cliquez sur **Calculer les moyennes** pour afficher votre tableau de résultats détaillés.
6.  (Optionnel) Vous pouvez vider complètement vos données sauvegardées en cliquant sur le bouton **Tout réinitialiser**.
